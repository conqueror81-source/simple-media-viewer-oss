Simple Media Viewer

iPhone・Android 向けの、テキストで操作するファイラー兼メディアビューアーです。端末内と NAS（SMB）にある動画・音楽・漫画（zip・rar・cbr・PDF）・画像・テキストを開けます。

オープンソースのソースコード

本アプリは、mpv・FFmpeg などのオープンソースのライブラリ（GNU LGPL）を同梱しています。対応するソースコードと、本アプリのために加えた変更（パッチ・ビルド手順）は GitHub のリポジトリ で公開しています。各ライブラリのライセンスは、アプリの「設定 > 全般 > ライセンス」で確認できます。
